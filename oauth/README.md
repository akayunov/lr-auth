ассершин фреймфорк - по сути еще один тип гранта, очень похожий на client credential, просто вместо логина пароля,
может быть любое подтверждающее утверждение(assertion). В качестве ассерции почти всегда используется jwt токен, но может быть и saml.
Чаще используется для обезличенного взаимодействия машина <-> машина, но позволяет в запросе так же указать идентификатор пользователя,
на правах которого будет выполнено действие.
